# John Doe — Monograph Portfolio

<p align="center"><strong>A theatrical portfolio template for thoughtful work and suspiciously confident typography.</strong></p>

This single-page React portfolio mixes case studies, personal context, motion, project artwork, and a contact footer. It takes the work seriously. The page itself knows better.

## What it is for

Adapting a polished monograph-style portfolio for a designer, researcher, visual storyteller, or wonderfully mysterious internet entity.

## What it includes

- Hero, about, journey, selected work, and contact sections
- Responsive layout with light and dark themes
- Project and discipline detail modals
- Editable content in src/data/content.json
- Motion, cursor details, and a few tasteful theatrics

## Run it

```bash
npm install
npm run dev
```

Useful checks:

```bash
npm run lint && npm run build
```

## Customize it

Start with src/data/content.json. Change the name, copy, projects, links, portrait, and résumé there before going spelunking through components like a brave little archaeologist.
